# 单位符号规范

依据 GB 3100~3102-1993《量和单位》。

## 三条铁律

1. **单位符号用正体**（不斜体、不加粗），只有量符号才用斜体。
2. **大小写有语义，写错就是错值**。`kW`（千瓦）与 `KW` 不是同一个东西；`Mbps`（兆比特每秒）与 `MBps`（兆字节每秒）差 8 倍。
3. **单位符号不加复数、不加句点**：写 `5 kg`，不写 `5 kgs`、`5 kg.`。

## 必须在数值与单位符号之间留一个半角空格

- ✅ `10 GB`、`200 km/h`、`3.5 kW`
- ❌ `10GB`、`200km/h`、`3.5kW`

**三个例外，不留空格**：百分号 `%`、千分号 `‰`、角度与温度 `°` `℃`。

- ✅ `15%`、`90°`、`25℃`
- ❌ `15 %`、`90 °`、`25 ℃`

## 中文单位与符号单位的区别

这是最容易混的一处，判断方法只有一条：**看单位是不是字母**。

| 类型 | 例子 | 数值与单位之间 | 空格来源 |
|---|---|---|---|
| 符号单位（字母） | `GB`、`kW`、`km`、`Mbps` | 必须有空格 | 单位规则（GB 3100） |
| 中文单位（汉字） | `台`、`元`、`人`、`天` | 只有一个空格 | 中文与数字之间的排版空格 |

也就是说，`5000 台` 里的那个空格**不是单位规则要求的**，而是「中文与数字之间加空格」这条排版规则带来的。所以：

- ❌ `5000  台`（两个空格）—— 不要因为"单位要空格"再补一个
- ❌ `5000台`（无空格）—— 这是排版问题，不是单位问题
- ✅ `5000 台`

这条区分很重要：**单位规则只管字母单位**。汉字单位的间距问题归排版规范（pangu、autocorrect 那类工具）处理，本 skill 不重复管。

## 常见错误对照表

| 错误 | 正确 | 含义 |
|---|---|---|
| `KW` / `kw` | `kW` | 千瓦 |
| `KWH` / `kwh` | `kWh` | 千瓦时（度） |
| `HZ` / `hz` | `Hz` | 赫兹 |
| `MHZ` / `GHZ` | `MHz` / `GHz` | 兆赫 / 吉赫 |
| `KM` / `Km` | `km` | 千米 |
| `KG` / `Kg` | `kg` | 千克 |
| `MA` / `Ma` | `mA` | 毫安 |
| `KV` / `Kv` | `kV` | 千伏 |
| `mb` | `MB` | 兆字节 |
| `mbps` | `Mbps` | 兆比特每秒 |
| `Gpbs` | `Gbps` | 吉比特每秒 |
| `M2` / `m2` | `m²` | 平方米 |
| `M3` / `m3` | `m³` | 立方米 |
| `KM/H` / `kmh` | `km/h` | 千米每小时 |
| `kpa` | `kPa` | 千帕 |
| `ml` | `mL` | 毫升 |

## bit 与 Byte：差 8 倍

- `b` = bit（比特），`B` = Byte（字节）
- 带宽、网速用 **bit**：`100 Mbps` 宽带
- 文件大小、存储用 **Byte**：`100 MB` 文件
- ❌ `网速 100mb` —— 歧义，应明确为 `100 Mbps`
- ❌ `100 MBps 宽带` —— 若指带宽，应为 `100 Mbps`

看到 `mb` 时先判断上下文：**网速/带宽/下载速率 → Mbps**，**文件/存储/内存 → MB**。

## 中文名称与符号不叠用

同一单位只保留一种写法，不要「中文名 + 符号」并排：

- ❌ `25 摄氏度℃`、`100 平方米㎡`、`5 千瓦时 kWh`
- ✅ `25℃`、`100 ㎡`、`5 kWh`

## 平方与立方的两种合法写法

`m²` 与 `㎡` 均可，但**同一文档内统一**。`m²` 更国际通用，`㎡` 是中日韩兼容字符，在 Excel 与老旧系统中兼容性更好。选定一种，全文一致。

## 复合单位

- 相除用斜线，且**只允许出现一次斜线**：`km/h` 正确，`km/h/s` 不推荐，应写 `km/(h·s)`
- 相乘用中点：`N·m`、`kW·h`
- 中文表述时可用「每」：`千米每小时`
